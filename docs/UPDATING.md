# テンプレートの更新を取り込む

GitHub のテンプレートから作ったリポジトリは、元のテンプレートと履歴がつながっていません（GitHub の仕様）。そのため、フォークの「Sync fork」のようなボタンはありません。更新は次のどちらかの方法で取り込みます。

何が変わったかは、テンプレートの [CHANGELOG.md](../CHANGELOG.md) に書いてあります。

v0.25.0 以降は、新しい版が出るとアプリが知らせます（画面の上のお知らせと、「設定」タブの「テンプレートの更新」（v0.27.0 までは「一覧」タブ））。自分の版より新しい版の「変わったファイル」を、古い順にすべて取り込んでください。

## 方法1：変わったファイルだけ貼り替える（GitHub の画面だけでできる）

### 1. 取り込む版を決める

1. 自分のアプリを開き、画面右上の版（例：`v0.23.0`）を確かめる
2. テンプレートの [CHANGELOG.md](../CHANGELOG.md) を開き、自分の版より新しい版をすべて確認する
   - 例：自分が v0.23.0 で、最新が v0.25.0 なら、v0.24.0 と v0.25.0 の2つ
3. 各版の「**更新するときの注意**」を読む。Azure の環境変数などの追加が書いてあれば、先に済ませる（手順は SETUP.md の該当する章）

### 2. ファイルを貼り替える（古い版から順に）

各版の「変わったファイル」を、1つずつ次の手順で貼り替えます。同じファイルが複数の版に出てくるときは、**最後に1回だけ**貼り替えれば十分です（テンプレートの最新の中身に変わるため）。

1. テンプレートで、そのファイルを開く（例：`src/app.js`）→ 右上の **Copy raw file**（コピーのアイコン）で中身をコピー
2. 自分のリポジトリで同じファイルを開く → 鉛筆アイコン（**Edit this file**）
3. 中身をすべて選んで消し（Ctrl+A → Delete）、コピーした中身を貼り付ける
4. **Commit changes** → そのまま **Commit changes**
   - 「（新規）」と書かれたファイルは、自分のリポジトリにまだありません。そのフォルダーを開き、**Add file** → **Create new file** で同じ名前のファイルを作って貼り付けます

### 3. 反映を確かめる

1. 自分のリポジトリの **Actions** タブで、デプロイ（Azure Static Web Apps CI/CD）が緑のチェックになるまで待つ（数分）
2. アプリを開き直し、画面右上の版が新しくなっていれば完了。「新しい版があります」と出たら **更新する** を押す

### 注意

- `src/app.js` と `src/srs.js` は組で動きます。片方だけ新しくすると動かないことがあるので、変わったファイルはすべて貼り替えてください
- `api/test/` のファイルはテスト用です。アプリの動きには関係しませんが、そろえておくと方法2に切り替えるときに楽です
- `src/seed/words.json`・`sentences.json`（教材）を自分で直している場合は、貼り替えると自分の直しが消えます。必要な行だけ足してください
- 学習の記録（復習の予定・発音の記録など）は Azure の Table にあるので、ファイルを貼り替えても消えません
- うまく動かなくなったら、Actions の画面でデプロイが失敗していないかを確認し、[Issues](https://github.com/yo-yon/english-trainer-template/issues) で知らせてください

## 方法2：git でまとめて取り込む（PC に Git がある人向け）

最初の1回だけ、自分のリポジトリとテンプレートを「つなぐ」作業をします。2回目からは、最後の2行だけで取り込めます。

```bash
cd english-trainer   # 自分のリポジトリを clone したフォルダー
git remote add template https://github.com/yo-yon/english-trainer-template.git
git fetch template

# --- 最初の1回だけ ---
# 自分のリポジトリを作った時点のテンプレートのコミットを、「取り込み済み」として記録する（ファイルは変わらない）
# <作成日時> は自分のリポジトリを作った日時（例：2026-11-10 21:00）。リポジトリの最初のコミットの日時で分かる
base=$(git log template/main --before="<作成日時>" -1 --format=%H)
git merge --allow-unrelated-histories -s ours "$base" -m "テンプレートとつなぐ"

# --- 毎回 ---
git fetch template
git merge template/main -m "テンプレートの更新を取り込む"
git push
```

- 自分で直したファイルと、テンプレートの更新が同じ場所を変えていると、「CONFLICT」と表示されます。表示されたファイルを開いて、`<<<<<<<` から `>>>>>>>` の間を、残したい内容に直してから `git add .` →`git commit` →`git push` してください
- Azure が追加したデプロイ用のファイル（`.github/workflows/azure-static-web-apps-*.yml`）は、テンプレートには入っていないので、そのまま残ります
