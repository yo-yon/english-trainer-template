# English Trainer

英語の技術セッションを聞き取り、質問や雑談ができるようになるための、自分専用の英語学習アプリです。1日30分。**あなた自身の Azure** に構築して使います。

- **単語**（10分）：間隔反復。技術語と一般語を交互に出題。新しい単語は英語を見て意味を4択、覚えた単語は「音だけを聞いて意味を4択」「日本語から英語を声で言う」「例文を音だけで聞いて文の意味を4択」を順に回す（聞いた瞬間に意味が浮かぶようにするため）
- **シャドーイング**（15分）：お手本 → 録音 → Azure AI Speech の発音評価（正確さ・流暢さ・完全さ、単語と音素ごとの点数）。結果には総評（Good / Almost / Keep practicing）と、点数の低い音の直し方を最大3つ表示。録音中はマイクの音量メーターで声が届いているか確認できる。評価のあとに「自分の声を聞く」「聞き比べ（自分→お手本）」で録音をその場で聞き返せる（録音は端末のメモリだけに置き、保存しない）
- **お手本の読み上げ**：Azure のニューラル音声（en-US-AvaNeural）。一度聞いた音声は端末に保存して再利用。使えないときはブラウザ内蔵の読み上げ
- **単語の発音練習**：シャドーイングでつまずいた単語だけを、文の中の2〜4語のまとまりで言い直して評価。違う音に聞こえたとき（d→t、r→l など）は直し方を表示。発音記号には口の形・舌の位置・声の出し方を添える
- **会話**（任意・gpt-5.4-mini が必要）：海外のカンファレンス・旅行・日常の15場面で AI とロールプレイ。同じ場面でも毎回、変化球と相手の性格が変わる。相手の発言は「訳を見る」で日本語訳を表示。自分の発言は🎧でその場で聞き返せる。最後に振り返り（よかった点・言い換え・覚えたいフレーズ）。聞き取りは Azure AI Speech
- **会話の道具**：聞き返す・確かめる・考える時間を作る・話をつなぐ・相づち・締めるの25表現（会話タブと会話中の「🧰」）。会話では1回だけ相手役が少し難しい言い方をして聞き返すきっかけを作り、振り返りで使えた表現と聞き返せたかを表示（判定は文字のパターンで、AI は使わない）
- **フレーズ帳**：会話の振り返りや場面の「使えるフレーズ」を「＋保存」で集める。保存した表現はシャドーイングの会話文として出題する
- **練習**（時間があれば）：
  - **瞬間作文**：日本語を見て英語を声に出す。判定は gpt-5.4-mini（お手本とほぼ同じなら AI を呼ばない。未設定なら自分で判定）
  - **ディクテーション**：練習した文を聞いて書き取る。AI は使わない
  - **苦手な音**：シャドーイングの記録から点数の低い音とコツを表示し、その音を含む文を今日のシャドーイングに足す
  - **今週のまとめ**（週1回）と**定着率**（7日以上あけた復習で覚えていた割合）
  - **単語クイズ**：意味・類義語・強勢・聞き取り。意味の判定は gpt-5.4-mini（任意）
- **フィードバック**：単語・文・クイズ結果の「👎」と、画面上部の「ご意見・要望」。自分の Azure に保存し、「一覧」タブで確認
- **作者にフィードバックを届ける（任意）**：本人が選んだものだけを、匿名で作者に送る。初期設定は「送らない」
- PC とスマホで同じ学習状況を使えます（サインインして使う Web アプリ）

## フィードバックの扱い

👎 や「ご意見・要望」は、まず**あなた自身の Azure**（Table）に保存されます。作者には届きません。

環境変数 `FEEDBACK_HUB_URL` を設定した場合だけ、「作者にも送る」を選んだフィードバックを、作者の受付に送ります。送ってもらった内容は、このアプリの改善に使います。

- **初期設定は「送らない」**。初回に一度だけお願いの画面が出ます。送る・送らないは、送るたびにも選べ、「一覧」タブでいつでも変えられます
- **送るもの**：フィードバックの種類とコメント（メール・URL・電話番号・長い数字は自動で消します）、対象の単語・文と点数、アプリのバージョン、PC かスマホか、ランダムな端末 ID
- **送らないもの**：名前、メールアドレス、サインインしたアカウント、録音した音声、あなたの Azure の情報、学習の記録
- **送り方**：あなたのアプリの API から作者の受付へ、サーバー間で送ります
- **削除の依頼**：このリポジトリの [Issues](https://github.com/yo-yon/english-trainer-template/issues/new/choose) で「送ったフィードバックの削除依頼」を選び、「一覧」タブに表示される端末 ID の先頭8文字を書いてください。Issue は誰でも見られるので、コメントの本文や名前は書かないでください
- 端末 ID を「作り直す」と、それより前に送ったものとは結び付かなくなります。削除を頼む可能性があるなら、作り直す前に控えておいてください

## 会社の環境で使うとき

- **社内のルールを先に確認してください。** 会社のサブスクリプションでリソースを作ってよいか、データの置き場所（このアプリは Japan East などに学習の記録を保存します）、社外への送信（作者へのフィードバック）が認められているか
- **サインイン**：Static Web Apps の既定の Microsoft Entra ID サインインは、どの Microsoft アカウントでもサインインできます。このアプリは、招待で `owner` ロールを付けた人だけが中に入れるようにしています（SETUP.md 手順9）
- **「管理者の承認が必要」と出る場合**：会社のテナントで、利用者によるアプリへの同意が止められていると、管理者の同意が必要になります（Microsoft Entra の仕様）。社内の管理者に相談してください
- **同意の画面の「組織の代理として同意する」にはチェックしないでください**。管理者のアカウントでこれにチェックすると、テナントの全員の分の同意になります
- 社外への送信が認められていない場合は、`FEEDBACK_HUB_URL` を設定しないでください（設定しなければ、作者には何も送られません）

## 構成

```
src/                 画面（静的ファイル。ビルド不要）
  app.js             画面のロジック
  srs.js             間隔反復と発音評価結果の整形（テストあり）
  seed/              初期データ（単語・文・会話の場面）
  staticwebapp.config.json  owner ロール限定・GitHub ログインのブロック（アプリの場所 src に置く必要がある）
api/                 マネージド Functions（Node.js 22 / v4 モデル）
  src/functions/     speech-token, state, card, settings, attempts, judge, roleplay, compose-judge, phrase, feedback, import
  src/roleplay.js ほか  会話・瞬間作文・フレーズ帳のプロンプトと入力の検査（テストあり）
tools/               週次レポート・教材の反映・対応済み化（GitHub Actions から実行）
.github/workflows/   Weekly report、Sync content、Close feedback（デプロイ用は構築時に Azure が追加）
docs/                週次の改善ループ・Claude の定期タスク・更新の取り込み方
```

## データ（Table Storage `learning`）

| PartitionKey | RowKey | 中身 |
|---|---|---|
| `word` | 単語ID | 単語・意味・発音記号・強勢・類義語・例文・カテゴリ（tech / general） |
| `sentence` | 文ID | 英文・訳・場面・カテゴリ（conference / conversation） |
| `card-word` / `card-sentence` | ID | 復習状態（間隔・易しさ・次回日・文は最高点） |
| `card-compose` / `card-dict` | ID | 瞬間作文・ディクテーションの復習状態 |
| `phrase` | フレーズID | フレーズ帳（最大500件） |
| `talk-YYYYMM` | 新しい順のキー | 会話の記録（文字だけ。音声は保存しない）と振り返り |
| `usage` | `roleplay-日付` / `compose-日付` | AI を呼んだ回数（1日の上限の確認用） |
| `settings` | `app` | 1日の新規数・クイズ成績・ランダムな端末ID（instanceId）など |
| `feedback` | 新しい順のキー | 👎（教材・判定）とご意見（機能・使い勝手・不具合）。種類・対象・コメント・対応状況 |
| `attempt-YYYYMM` | 新しい順のキー | 発音評価の結果（単語・音素ごとの点数） |
