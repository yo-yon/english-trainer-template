フィードバック

作者にフィードバックを届けませんか？

このアプリは、使う人の 👎 やご意見をもとに、毎週少しずつ改善しています。よろしければ、あなたのフィードバックも作者に届けてください。初期設定は「送らない」で、送る・送らないは、送るたびにも選べます。

    送らないもの

      送ったフィードバックは、アプリの改善だけに使います。削除してほしいときは、GitHub の Issues で、端末 ID の先頭8文字 を添えて依頼してください（README の「フィードバックの扱い」を参照）。
